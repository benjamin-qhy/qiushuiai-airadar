# Domain Docs

This repository uses a single-context layout:

- `CONTEXT.md`: project terminology and domain knowledge
- `docs/adr/`: important architecture decisions

Before working, read the relevant files when they exist. Missing files should
not block work; `/domain-modeling` creates them when needed.

Use terminology defined in `CONTEXT.md`. If proposed work conflicts with an
existing ADR, report the conflict explicitly instead of silently overriding it.
