# 采集设置页面组件选择

## 目标

把平台接口、供应商调用顺序和连接测试从信源管理中拆出，形成管理区独立的“采集设置”页面；所有状态和操作结果都在用户当前操作的位置解释清楚。

## 组件选择

- 页面沿用现有 `PageHeader`、`Card`、`Input` 和 `Button`，遵循根目录 `design.md` 的纸张、细线和实体控件规则，不引入新的视觉体系。
- 供应商调用顺序继续使用带文字标签的上移、下移按钮，避免拖拽交互在键盘和触屏上的隐性问题。
- 连接测试、保存和清除结果使用卡片内 `role=status` / `role=alert` 的就地反馈；异步执行时按钮显示进行中状态并防止重复提交。
- 这是 REST 配置页面，不承载对话或 Agent 会话，因此不使用 assistant-ui 会话 Runtime；业务真相仍由后端接口和持久化配置提供。

## 状态语义

“已配置 / 未配置”只描述当前打开的运行环境。开发环境与正式安装环境保持隔离，页面不会把另一套环境的密钥状态误报为当前状态，也不会自动复制密钥。
